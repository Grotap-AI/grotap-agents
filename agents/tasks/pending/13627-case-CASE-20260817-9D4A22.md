# Task: Bug: platform — DEFECT (found by review gate while merging case 157824c4 "My apps not working")

## Context
Component: platform

## Requirements

DEFECT (found by review gate while merging case 157824c4 "My apps not working"):

`LandingRedirect` in frontend/src/App.tsx re-fires its route-memory restore on
EVERY in-session navigation to `/`, not just on a cold page load. TopNav's
"My Apps" tab points at `/` (frontend/src/components/TopNav.tsx:184), so any
user whose last remembered route is a manager section clicks "My Apps" and is
bounced straight back to where they were — My Apps is unreachable.

ROOT CAUSE: the once-only guard is `const hasRedirected = useRef(false)`
(App.tsx ~line 205). React Router unmounts the `path="/"` element when you
navigate away and mounts a fresh one when you come back, so the ref resets and
the redirect runs again. The feature's stated intent is "persist last visited
platform page ACROSS SESSIONS" — that needs a per-page-load guard, not a
per-mount one.

Case 157824c4 (merged as a12a6c27) only narrowed MEMORABLE_PATHS from
`['/', '/apps/my-beta', '/apps/buy', '/apps/beta', ...managers]` down to
`['/', ...managers]`. That removes the exact instance the owner reported
(My Apps -> My Beta) but leaves the same trap on all five manager paths:
/app-manager, /brand-management, /knowledge-manager, /agent-manager,
/agent-teams.

FIX SCOPE (frontend/src/App.tsx only, ~lines 163-221):
1. Make the restore fire at most once per page load. Either a module-level
   `let restoreConsumed = false` flipped on first evaluation (module scope
   survives remounts within a page load, resets on reload), or a sessionStorage
   sentinel. Do NOT keep using a component-scoped useRef.
2. Once (1) is in, restore '/apps/my-beta', '/apps/buy', '/apps/beta' to
   MEMORABLE_PATHS and update the comment block — 157824c4 dropped them purely
   as a workaround, which degraded "come back where you left off" for those
   three tabs. Keep /apps/suggest and /apps/vote excluded (action pages).

VERIFY (both must hold):
- From /app-manager, click "My Apps" in the brand dropdown -> lands on My Apps
  and STAYS there. Same from /agent-teams and from /apps/my-beta.
- Visit /apps/buy, reload the browser at `/` -> restores /apps/buy.
- Pop-out windows (?mode=app) still never record or restore a route.
