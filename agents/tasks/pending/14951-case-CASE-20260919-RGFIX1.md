# Task: Bug: Platform — QuoteWalkReviewPage CSV download creates an anchor element and calls .click() wi

## Context
No additional context provided.

## Requirements
QuoteWalkReviewPage CSV download creates an anchor element and calls .click() without appending it to document.body first. Modern Chrome tolerates this but Firefox and some mobile browsers require the element to be in the DOM for programmatic download clicks to fire. Fix: document.body.appendChild(a) before a.click(), then document.body.removeChild(a) after. File: frontend/src/pages/scantap/tour/QuoteWalkReviewPage.tsx, handleExportCsv function.
